# 😂 Meme Generator (React App)

A fun and interactive Meme Generator built using React that allows users to create custom memes by adding text to images in real-time.

---

## 🚀 Features

- 🖼️ Select desired image
- ✍️ Add top and bottom text to memes
- ⚡ Real-time preview of meme changes
- 🎨 Clean and responsive UI
- 💾 Download generated memes (if implemented)

---

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- CSS / Tailwind (if used)
- HTML5 Canvas (if used)

---

## 📸 How It Works

1. Select an image  
2. Add custom text (top & bottom)  
3. Preview meme instantly  
4. Download or share  

Meme generators typically allow users to add captions to images and customize styling like text position and size.
